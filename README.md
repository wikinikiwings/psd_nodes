# PSD Export (ComfyUI)

Экспорт результатов сегментации в слоёный PSD: **каждая маска → отдельный слой с полной копией картинки и настоящей редактируемой маской слоя**, названный по промту, из которого он получен.

Маска именно маска, а не выжженная прозрачность: в фотошопе её можно подправить кистью, скрытые пиксели никуда не делись.

## Зависимости

```
pip install "psd-tools>=1.11"
```

Ставить нужно в тот же python, в котором работает ComfyUI. Зависимости у самой psd-tools лёгкие (numpy, Pillow, attrs, typing-extensions), под Windows есть готовые колёса для python 3.10–3.14.

Нижняя граница именно 1.11: в этой версии переименовали API записи — `PixelLayer.frompil(..., name=...)` вместо `layer_name=` и `Group.new(parent, name, open_folder)` вместо `Group.new(name, open_folder, parent=...)`. На 1.10.x нода откажется грузиться с внятной ошибкой, а не молча назовёт все слои `Layer`. Проверено на 1.14.2 и 1.18.0.

## Нода `Save PSD (masked layers)` — категория `image/psd`

| | |
|---|---|
| `image` | исходная картинка. Если картинок столько же, сколько масок — берётся своя на каждый слой, иначе одна на всех |
| `masks` | `MASK`. У ноды включён `INPUT_IS_LIST`, поэтому она собирает маски со **всех** прогонов графа: промт-лист разворачивается в N выполнений SAM3, и все результаты приходят сюда разом |
| `prompt_list` (опц.) | `LIST` — выход `Prompt List (Dynamic)` из пака simple_tools |
| `names` (опц.) | `STRING` — можно подать `prompt_strings` вместо `prompt_list` |
| `filename_prefix` | как у SaveImage; файл падает в `output/` |
| `include_original` | добавить исходник нижним слоем |
| `only_first_visible` | открыть файл с одним видимым слоем (верхним — это первый промт), остальные выключены |
| `invert_masks` | если маска помечает то, что нужно скрыть (advanced) |
| `group_per_prompt` | несколько детекций одного промта — в группу с его именем (advanced) |
| `crop_to_mask` | хранить слой обрезанным по границам маски: файл меньше, но пиксели снаружи теряются (advanced) |
| Выходы | `psd_path`, `layer_count` |

Файл пишется в `output/`, во временную папку ничего не кладётся. После прогона на ноде появляется кнопка **⬇ download &lt;имя&gt;.psd** — скачивает файл через браузер (нужно, когда ComfyUI крутится не на той машине, где вы работаете). Ссылка запоминается в workflow, так что после перезагрузки страницы кнопка всё ещё работает.

### Как сопоставляются имена и маски

* если число прогонов совпадает с числом имён — имя берётся у своего прогона; когда SAM3 нашёл на один промт несколько объектов, слои называются `jeans 1`, `jeans 2`, …;
* если пришёл один батч масок и столько же имён — пара к паре;
* если имён меньше — недостающие называются `layer N`.

Порядок слоёв в панели фотошопа сверху вниз повторяет порядок промтов, `original` — в самом низу.

## Типовой граф

```
Prompt List (Dynamic) ──prompt_strings──> SAM3 Text Segmentation ──masks──┐
                     └──prompt_list───────────────────────────────────────┤
Load Image ──────────────────────────────────────────────image───────────>│
                                                    Save PSD (masked layers)
```

`prompt_strings` — list-выход, поэтому SAM3 отработает по разу на каждый промт; `prompt_list` идёт в PSD-ноду одним объектом и задаёт имена.

## Размер файла

Каждый слой хранит полную копию картинки (сжатие RLE). Для 2048×2048 и десятка слоёв это десятки-сотни мегабайт — если критично, включите `crop_to_mask`.
